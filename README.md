# GameBoyEmulator WIP

> **Status:** WIP (Work in Progress)

## Description

A Game Boy emulator project for learning purposes, and currently under development.
## Goals

- **CPU Emulation:** Full instruction set, registers, flags, and timing --> Mostly done.
- **GPU / Video Rendering:** Backgrounds, sprites, palettes ---> Currently worked on.
- **Input Handling:** Keyboard or gamepad mapping for A, B, Start, Select, and D-pad --> TODO.
- **Memory Management:** ROM/RAM emulation, memory banking, and simple MBC support ---> Some work done.
- **Optional Audio (future):** Basic sound channel emulation ---> Might be skipped.
